# Alteryx Learner Data Preparation & Validation Workflow

## 📌 Project Overview

This project demonstrates the use of Alteryx Designer to prepare, validate and transform learner data for downstream analysis and student-support processes.

## 🎯 Project Objectives

* Prepare and organise learner records.
* Apply data quality and validation rules.
* Identify and separate invalid records.
* Create structured outputs for further analysis.
* Improve the reliability and consistency of learner data.

## 🛠️ Tool Used

* Alteryx Designer

## ⚙️ Workflow Process

1. Import source data.
2. Prepare and transform records.
3. Apply validation and data quality checks.
4. Separate records according to the configured rules.
5. Generate outputs for review and further analysis.
